# Fonts for generated images

`DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` (DejaVu Fonts 2.37) draw the link-preview cards
(`App\Support\LinkPreview`, #4652). They cover the accented and Cyrillic city names ETS2 uses.
